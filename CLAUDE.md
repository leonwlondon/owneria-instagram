# Owneria · Instagram diario (@owneria.mx)

Publica dos veces al día en Instagram. **Mañana (8:30 CDMX):** el artículo del blog del día (o uno anterior pendiente), rotando formatos: reel animado (MP4 9:16 con tipografía en movimiento y el dato contando), carrusel (puntos + «el dato» + «el mapa» + «para llevarte») e imagen de dato. **Tarde (19:00 CDMX):** una pieza propia de `src/banco.ts` (no del blog): casos reales antes/ahora, «lo que ya construí», reels «Pregúntale a tu negocio» (datos de ejemplo), glosario del dueño e ideas de León; las series se turnan. Tono editorial, no comercial. Sin aprobación: automático. **El banco tiene 47 piezas (~47 días):** cuando la Action avise «se acabó el banco», escribir más con material real.

- **Código:** esta carpeta → GitHub `leonwlondon/owneria-instagram`. Corre en GitHub Actions (`.github/workflows/diario.yml`), 14:30 UTC (mañana) y 01:00 UTC (tarde); `TURNO=manana|tarde`.
- **Flujo:** `src/diario.ts` lee `https://owneria.mx/api/public/articulos` (ruta del sitio, solo artículos, sin noticias) → elige qué toca según el turno → `src/contenido.ts` arma las láminas (portada, hasta 5 secciones `##`, cierre) y el texto con hashtags → `src/render.ts` dibuja JPEG 1080×1350 con 3 temas que rotan (noche, azul, claro, azul) para que la cuadrícula corra en diagonal, el aro del logo en grande y una línea con nodos continua entre láminas (satori + resvg + sharp, Poppins y logo en `fuentes/` y `marca/`) → reels con `src/reel.ts` (satori cuadro por cuadro + ffmpeg-static) → sube `img/<slug>/` al repo → Instagram lo baja de GitHub Pages `leonwlondon.github.io/owneria-instagram` (repo público con Pages activo) → publica con la Graph API (REELS, CAROUSEL o imagen) → anota en `publicados.json`.
- **Conexión con Meta (24-nov-2026):** app «Owneria Publicador» (id 2104125926897964, modo desarrollo, sin portafolio) en developers.facebook.com; página de Facebook «Owneria» (facebook.com/owneria.mx, id 1448115598388510) ligada a @owneria.mx (IG id 17841464279205781). El token es de la página, sacado de un token de usuario ampliado: no caduca, pero deja de servir si León cambia su contraseña de Facebook, quita la app o deja de administrar la página. Para renovarlo: Explorador de la API Graph con la app → Generate Access Token (permisos pages_show_list, pages_read_engagement, business_management, instagram_basic, instagram_content_publish) → ampliar en el depurador → `1448115598388510?fields=access_token` → `gh secret set IG_TOKEN`.
- **Secretos (GitHub Actions, nunca en el código):** `IG_USER_ID` (cuenta de Instagram profesional) e `IG_TOKEN` (token de página de larga duración con `instagram_content_publish`). Opcional `IG_API` (por omisión `https://graph.facebook.com/v23.0`).
- **Probar sin publicar:** `PRUEBA=1 bun src/diario.ts` (o «Run workflow» con «Solo dibujar»). Muestras locales: `bun src/muestra-reel.ts 7 noche`, `bun src/muestra.ts 10` y `bun src/hojas.ts` → `muestras/` (hojas por carrusel y `perfil.jpg`).
- **Si falla:** la Action queda en rojo y GitHub avisa por correo. Volver a correrla es seguro: lo publicado ya está en `publicados.json`.
- **Imágenes OG del blog:** `bun run og` (`src/og.ts`) dibuja 1200×630 por artículo y noticia en `../app/public/blog/og/` y la lista `../app/src/content/blog/og.ts`; luego push del sitio y Publish en Lovable. `--todas` las rehace.
- **Reglas:** todo sale del artículo publicado; no inventar cifras ni casos.
- **Serie Método OWNER (24-nov-2026, publicada con OK de León):** 6 carruseles fuera del flujo diario, en `src/metodo.ts` (textos copiados de `app/src/components/owneria/Metodo.tsx`). Portadas con letra gigante, fondo noche igual y una línea con nodo a la misma altura, para que la cuadrícula lea O W N / E R + portada «Método OWNER · Recupera el mando de tu negocio». Cada letra: letra, fase (inglés y español), qué incluye, entregable, cierre a owneria.mx/metodo. `bun src/metodo.ts` dibuja en `img/metodo-owner/` y arma `muestras/metodo-perfil.jpg`; la Action manual `.github/workflows/metodo.yml` publica en orden inverso (portada, R, E, N, W, O), una por minuto, y anota en `metodo-publicado.json` (volver a correrla no duplica). Cada post nuevo recorre la cuadrícula: la palabra solo se lee alineada cuando lo publicado después es múltiplo de 3.
